04 Studi Kasus Troubleshooting

Contoh alur penanganan insiden pipeline CI/CD dari laporan masuk hingga layanan kembali normal — didokumentasikan langsung dari sistem kerja sehari-hari.

Sistem
Pipeline CI/CD (Jenkins → OpenShift)
Trigger
Laporan user, SLA 1x24 jam
Status Awal
Build #34 — Gagal di stage App Push
Status Akhir
Deploy to Staging — Sukses
REQUEST
01 — Laporan Masuk
Pipeline gagal build, deployment tertahan

User melaporkan pipeline deployment tidak bisa selesai. Berdasarkan SLA 1x24 jam, penanganan langsung dimulai dengan mengecek Stage View di Jenkins untuk memastikan tahap mana yang gagal.

Stage View — Build #34 gagal di stage "App Push" setelah 2 menit 27 detik
CEK
KONFIG
02 — Investigasi
Menelusuri konfigurasi repository & credential di Jenkins

Masuk ke halaman Configure job untuk memeriksa apakah Repository URL dan credential yang terpasang masih valid dan sesuai dengan yang didefinisikan di source control — langkah standar sebelum menduga masalah ada di sisi kode aplikasi.

Jenkins → Configure → Advanced Project Options (repository & credential disamarkan)
PERBAIKAN
03 — Tindakan
Root cause ditemukan di Jenkinsfile, perbaikan via merge request

Root cause ditemukan pada variabel konfigurasi registry & image pull secret di dalam staging.Jenkinsfile yang tidak lagi sinkron dengan environment target. Perbaikan dilakukan langsung di GitLab dengan membuat merge request ke branch patch, menjaga jejak perubahan tetap terdokumentasi dan bisa di-review.

GitLab → Edit file → staging.Jenkinsfile (nilai registry & credential disamarkan)
RESOLVED
04 — Hasil
Pipeline berjalan normal hingga deploy ke staging

Setelah perbaikan di-merge, pipeline di-run ulang dan seluruh stage berhasil dilalui — mulai dari Git Clone, App Build, App Push, hingga Deploy to Staging. Log Blue Ocean mengonfirmasi setiap langkah deployment (apply manifest, set image, rollout restart) berjalan sesuai rencana tanpa error.

Blue Ocean — seluruh stage sukses, deployment ke staging selesai (domain internal disamarkan)

Nama domain, hostname registry, dan credential ID pada tangkapan layar telah disamarkan untuk menjaga kerahasiaan sistem instansi.
